# Генератор Word-документу диплома (build/)

Скрипт `build.py` збирає файли з папки `../content/` у єдиний документ
`../output/diplom.docx`, оформлений строго за **методичкою ЗНУ 2025**:

- поля 30 / 10 / 20 / 20 мм (ліве / праве / верхнє / нижнє);
- шрифт Times New Roman 14;
- міжрядковий інтервал 1.5;
- абзацний відступ 1.25 см;
- вирівнювання за шириною;
- заголовки розділів — великими літерами, 14 напівжирний, центр;
- підрозділи — з абзацу, 14 напівжирний;
- курсив для слів *об'єкт, предмет, мета, гіпотеза, методи* у вступі;
- автоматична заміна `"…"` → `«…»`, ` -- ` → ` — `;
- нумерація сторінок у правому верхньому куті (поле PAGE);
- кожен новий розділ — з нової сторінки.

---

## Запуск на VPS (Ubuntu 24.04)

```bash
# 1) клонуємо репозиторій
git clone https://github.com/anatolyiusau-alt/diplom.git
cd diplom

# 2) ставимо python-docx (одна залежність)
python3 -m pip install -r build/requirements.txt
#    або, якщо pip немає в системі:
#    sudo apt update && sudo apt install -y python3-pip

# 3) запускаємо генератор
python3 build/build.py

# 4) забираємо файл
ls -la output/diplom.docx
```

Якщо хочеш ізолюване середовище:

```bash
sudo apt install -y python3-venv
python3 -m venv .venv
source .venv/bin/activate
pip install -r build/requirements.txt
python build/build.py
```

```

├── build/
│   ├── build.py            ← головний генератор docx
│   ├── config.py           ← метадані (ім'я, керівник, ОПП, рік)
│   ├── requirements.txt    ← python-docx

│   ├── 03_referat_ua.md    ← реферат укр

│   ├── 06_vstup.md         ← ВСТУП
│   ├── 07_rozdil_1.md      ← РОЗДІЛ 1
│   ├── 08_rozdil_2.md      ← РОЗДІЛ 2
│   ├── 09_rozdil_3.md      ← РОЗДІЛ 3
```

**генеруються з `config.py`** (їх не треба писати вручну в `.md`).

## Синтаксис markdown у `content/*.md`

| Конструкція | Що генерує |
| --- | --- |
| `# ВСТУП` | Заголовок розділу (центр, 14, BOLD, UPPER) |
| `## 1.1. Назва підрозділу` | Заголовок підрозділу (з абзацу, 14, BOLD) |
| `### Виділена фраза` | Жирний абзац-підзаголовок |
| Звичайний рядок | Абзац (justified, абзац 1.25, інтервал 1.5) |
| `*курсив*` | Курсив у тексті |
| `**жирний**` | Жирний у тексті |
| `<pagebreak/>` | Розрив сторінки |
| `<center>...</center>` | Центрований рядок |
| `<center bold>...</center>` | Центрований напівжирний |
| Порожній рядок | Розділювач абзаців |

**Лапки** і **тире** перетворюються автоматично:
- `"текст"` → «текст»
- ` -- ` → ` — `
- В складних словах ставимо звичайний `-` (соціально-економічний).

## Що зробити перед першим запуском

1. Відкрити `build/config.py` і заповнити свої дані:
   - повне ПІБ, група, ініціали;
   - П. І. Б. наукового керівника та його посада/ступінь;
   - П. І. Б. рецензента;
   - дату подання (`SUBMISSION_DATE`).
2. Запустити `python3 build/build.py`.
3. Відкрити `output/diplom.docx` у Microsoft Word або LibreOffice.
4. Перевірити поля (`Layout → Margins → Custom`): 3 / 1 / 2 / 2 см.
5. У Word: виділити зміст (Ctrl+A на сторінці), F9 — оновити поля сторінок.

## Послідовність роботи над текстом

Файли в `content/` редагуєш у будь-якому порядку. Після кожної правки
запускай `python3 build/build.py` — і переглядаєш результат у Word.

Рекомендований порядок написання (за графіком 7 днів):

| День | Файл(и) |
| --- | --- |
| 1 | `06_vstup.md` (чорновик), `07_rozdil_1.md` → 1.1 |
| 2 | `07_rozdil_1.md` → 1.2, 1.3 |
| 3 | `08_rozdil_2.md` → 2.1, 2.2 |
| 4 | `08_rozdil_2.md` → 2.3, `09_rozdil_3.md` → 3.1 |
| 5 | `09_rozdil_3.md` → 3.2 |
| 6 | `09_rozdil_3.md` → 3.3, `10_vysnovky.md` |
| 7 | `11_literatura.md`, `12_dodatky.md`, `03_referat_ua.md`, `04_abstract_en.md`, фінальна вичитка |

Вступ остаточно редагується **в кінці**, коли все написано (так радить методичка).
